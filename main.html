Asistente de Actividad Laboral

Mantén tu equipo activo de forma segura y sin instalar nada. Solo copia y pega un comando en PowerShell (la ventana azul).

🔍 Código visible 🗂️ No toca archivos ⌨️ Simula Scroll Lock ⏱️ Cada 4 minutos

1) Copia este comando (una sola línea)

Después solo tendrás que pegarlo en PowerShell y pulsar Enter.

$w = New-Object -ComObject WScript.Shell; while($true) { $w.SendKeys('{SCROLLLOCK}'); Start-Sleep -Seconds 240 }
✅ ¡Copiado!
💡 Consejo: si el botón de copiar no funciona por políticas del navegador, usa “Seleccionar texto” y luego Ctrl + C.
🧠 Hecho para personas sin conocimientos técnicos.
Compatible con Windows (PowerShell).

Guía rápida (3 pasos)

  1. 1️⃣
    Haz clic en “Copiar Código” El comando quedará en tu portapapeles.
  2. 2️⃣
    Abre PowerShell Pulsa Inicio, escribe PowerShell y abre la app (ventana azul).
  3. 3️⃣
    Pega y ejecuta Haz clic derecho dentro de la ventana azul para pegar y pulsa Enter.

🔒 Seguridad

El código es transparente: no descarga nada, no accede a tus archivos y no envía datos. Solo simula una pulsación de tecla invisible (Scroll Lock) cada 4 minutos.

⛔ Cómo detenerlo

Para parar el proceso, simplemente:

• Cierra la ventana azul (PowerShell), o
• Pulsa Ctrl + C dentro de PowerShell.

⚠️ Nota: este tipo de uso puede estar regulado por políticas internas de tu empresa. Úsalo con criterio.
