# Abre MiAutoClicker.exe (puede pedir permiso de administrador para teclas rápidas).


# Rellena:

- Horas y Minutos de duración total.

- Intervalo entre clics en segundos (por ejemplo, 2.7).

- (Opcional) Teclas:

    - Consultar tiempo (por defecto “i”).

    - Detener (por defecto “s”).


# Pulsa Iniciar. El programa hará clic automáticamente hasta que:

- termine el tiempo, o

- pulses Detener, o

- uses la tecla rápida de detener.


# El tiempo restante se ve en grande en la ventana.



## Consejos

- Si las teclas rápidas no funcionan, ejecuta como Administrador o usa los botones de la ventana.

- No muevas el ratón si quieres máxima precisión en los clics.

- Cierra la ventana para salir (si está clicando, te preguntará).
